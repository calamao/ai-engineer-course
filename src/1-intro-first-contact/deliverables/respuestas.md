# ¿Qué es un LLM?

Un **LLM (Large Language Model)** es un modelo de inteligencia artificial entrenado con enormes cantidades de texto para entender y generar lenguaje natural. Estos modelos utilizan redes neuronales profundas, específicamente arquitecturas basadas en **transformers**, que procesan el texto token por token (palabras o fragmentos de palabras) para captar patrones, significados y relaciones entre conceptos.

El entrenamiento de un LLM implica aprender de miles de millones de palabras de internet, libros, artículos y otros textos públicos. A través de este proceso, el modelo desarrolla la capacidad de predecir cuál será la siguiente palabra en una secuencia, lo que le permite mantener conversaciones coherentes, responder preguntas, escribir textos, traducir idiomas y realizar tareas complejas relacionadas con el lenguaje.
